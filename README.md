## 0. 주제

### 키오스크 (Kiosk) 구현
> 사용자가 키오스크를 통해 메뉴에 존재하는 물품을 돈으로 구매하고, 장바구니에 담으며 거래하는 프로그램 구현

<br />

## 1. 작성자 
- (메타버스 프로그래밍 15기) 주성재

<br />

## 2. 구현 및 구조 설계

### (1) 상위 클래스 `Item`
- 하위 클래스로 `FriedChicken`, `SpiceChicken`, `BeefBurger`, `ChickenBurger`, `FrenchFries`를 가지고 있음
- 가격의 계산을 수행하는 메서드를 추상 메서드로 두어 하위 클래스들이 자기만의 방식으로 계산할 수 있게 하였음
- 가상 함수로 자신의 정보를 출력하는 함수를 만들었으며, 하위 클래스들은 base를 통해 Item의 출력을 사용하고 자신의 추가 정보를 덧붙이는 방향으로 설정하였음

### (2) 인터페이스 `ISaleable`
- 우선, 세일을 한다는 공통점으로 묶어두고 나중에 개별 기능을 구현하기 위해 설계 해두었는데 기발한 아이디어가 떠오르지 않아 보류 중에 있음

### (3) 클래스 `User`
- 구매 계산을 하는데 사용할 총 금액을 가지고 있음
- Item을 담는 List인 Basket을 private로 가지고 있어 Item들을 임시로 담고 장바구니에 있는 요소들을 구매하거나 초기화 할 때 참조하기 쉽게 하였음 

### (4) 클래스 `Kiosk`
- 메뉴판 List를 관리하게 하였음
- Item의 하위 클래스들과 User 클래스 사이에서 메서드를 호출하며 연산을 담당함

### (5) 클래스 `ConsoleInput`
- 제공된 메서드
